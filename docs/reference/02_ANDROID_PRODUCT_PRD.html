1 · Product definition

Working name: Orbit — Focus & Timer. Category: Productivity. Platform: Native Android (phone initially; tablets responsive). Promise: “One tap to start; your time remains yours.”

Primary value

Two timers, one home

Focus mode handles classic Pomodoro, flexible sessions and breaks. Quick Timer handles arbitrary countdowns, stopwatch and saved intervals, without forcing a productivity ritual.

Emotional value

Calm progress

Original orbit arc, softly glowing constellation, gentle session celebration. No punitive graphics or mandatory streak recovery purchases.

Technical value

Background trustworthy

Persistent session state, monotonic time, restart recovery, completion alert, in-notification controls, offline-first.

North-star outcome

Weekly completed intentional sessions per weekly active user, segmented by Focus and Quick Timer. Guardrails: D1/D7 retention, notification opt-out, session abandonment, low crash/ANR, adverse permission signals and user support complaints.

Core principles

  • Start quickly: at most one tap from the default focus view; switch to Quick Timer in one tap.
  • Never depend on keeping the Activity alive. A timer is a time interval, not a running animation.
  • Respect choice: no forced sign-in, no blocking notifications by default, no aggressive streak guilt or ads during focus.
  • Model calm: subtle animations, reduce-motion mode, haptic toggle, high contrast and large touch targets.
  • Use native Android instead of cross-platform for precise platform integrations and widget behavior.

Bottom navigation

Timer (home with two-mode segmented control) · Tasks (simple list) · Insights (history/report) · You (themes/settings).

Keep quick action within top of Timer, not buried under an overflow menu.

Onboarding

Screen 1: value proposition → Screen 2: choose default (Focus/Timer) → Screen 3: optional 25/5 setup → Home. Ask notification permission only after the first session starts, with contextual explanation. No forced login.

Critical journeys

  1. First Pomodoro: launch → Focus active → 25 min already selected → Start → device locked → user receives end signal → Short Break prompt → next focus. Track whether completion was delivered and independently stored.
  2. One-off kitchen timer: launch → Timer tab → select 15 min or input 12:30 → Start → lock → alert → Done. It does not enter the focus reports by default.
  3. Interrupted focus: start → pause via notification → resume 4 min later → end at adjusted elapsed time; no invented work minutes.
  4. Process killed: session persisted; notification may be subject to OS policy; reopen → reconstruct remaining from authoritative deadline → display correct current state and reconcile unprocessed due stage.
  5. Permission denied: countdown still works visually and recovers; show honest “alerts may be delayed” status; offer settings link; do not crash or trap user.

RUNNING → COMPLETED when due; RUNNING/PAUSED → CANCELED when stopped; a completed Focus stage → BREAK_READY (manual) or BREAK_RUNNING (auto-start preference). Persist stage number; never count skipped stages as completed. See engineering spec for timer timebase.

Content and tone

Neutral copy: “Session complete,” “Ready for a short break?”, “You focused for 25 minutes.” Avoid “You failed,” streak threats, punitive dying assets, fake scarcity, dark patterns or unsubstantiated health-treatment claims.

7 · Monetization and ASO

Launch economics

Free forever: all timers, cycles, alerts, pause/resume, local history and core accessibility settings. Potential Plus: advanced reports, expanded history views/export, art themes, sound packs, premium widgets. No interstitial ads during or at completion of a session.

Subscription prices are testable hypotheses in the research document, not commitments.

Play Store listing

Provisional name: Orbit: Pomodoro & Timer (must verify trademark and metadata length). Short positioning: “Focus sessions, quick countdowns and calm progress.” Screenshot sequence: Home dual mode → Active timer → Timer presets → Tasks → Insights → Themes. Show truthful features only.

Keywords to research: pomodoro timer, focus timer, study timer, countdown timer, stopwatch, productivity.

Activation experiments

  1. Home startup: last used mode vs Focus default.
  2. Small starter set: 25/5 baseline vs 25/5 + 5-minute mini-sprint.
  3. Discovery: show Quick Timer tile at top vs segmented tabs only.
  4. Optional milestone visual on/off; measure retention without compromising completion success.

8 · Delivery roadmap and completion gates

Sprint A — foundations

Native project, module boundaries, design tokens, Room, DataStore, reproducible build, fake clock and timer reducer unit tests.

Sprint B — timers & alarms

Focus and Quick Timer end-to-end; cold-start restore, process kill, reboot and device idle behavior; reconcile all transitions.

Sprint C — visual polish & tests

Build gallery screens in Compose, navigation, animations with reduced motion, TalkBack, settings, notification and quick actions.

Sprint D — learning loop & launch

Tasks, basic insights, privacy policy, beta, in-app feedback, store screenshots, release signing, internal/closed testing and staged release.

Release gate: No public release until alarms, process death, timezone change, daylight saving time, notification-denied and app update tests pass on actual Android devices. A pretty timer that silently finishes late is not release-ready.
