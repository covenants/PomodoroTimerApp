What to ask the coding agent to build

First, ship a trustworthy clock.

Timers remain accurate across sleep, screen-off, rotation, activity recreation and process death. Completion is idempotent. No reliance on decrementing an in-memory second counter.

Then, create the frictionless user experience.

Start in one tap, presets in two. Focus and Quick Timer exist equally, with strong notification controls, custom interval profiles, and accessible typography.

Finally, layer in habits, insights and thoughtful monetization.

Focus streaks, optional ambient sound, widgets, simple tasks, local-only history, optional premium themes & advanced reports. Never penalize interruptions or paywall core timing.

Product thesis

Instant

Launch → select 25, 5, 15, 30, 45 or custom → start. Returning users should land on their last mode.

Trustworthy

Session survives lifecycle events. Correct time matters more than animations and complex gamification.

Worth keeping

Minimal overhead, motivating insights, elegant themes, quiet tone, no required account or app-blocking permission.
