## Android launcher icon

The Android icon is an adaptive icon with separate background and foreground layers:

- `app/src/main/res/drawable-nodpi/ic_launcher_bg.png` — midnight gradient, glow and stars.
- `app/src/main/res/drawable-nodpi/ic_launcher_fg.png` — transparent orbit ring, mint progress arc,
  central planet and four-point star.
- `app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` — adaptive icon for API 26–32.
- `app/src/main/res/mipmap-anydpi-v33/ic_launcher.xml` — adds a monochrome layer for themed icons.
- `app/src/main/res/mipmap-*/ic_launcher.png` and `ic_launcher_round.png` — legacy density fallbacks.
- `app/src/main/res/drawable/ic_launcher_monochrome.xml` — themed-icon silhouette.

The foreground stays inside Android's adaptive-icon safe zone, so launchers can mask it to a circle,
squircle, rounded square or teardrop without cutting the ring.

## Regenerate

From the repository root:

```bash
python tools/generate_assets.py
```

The script uses Pillow. It recaptures nothing itself — it composites the raw screenshots in
`docs/screenshots/`. To refresh those, install the debug APK on a device/emulator and capture the
eight source screens listed in the README. The store screenshots are generated at 1080 × 1920.
